Settlement Item Entity

# Overview

The Settlement Item entity represents the financial contribution of a specific Order Item to a Seller Settlement.

A Settlement can contain multiple Settlement Items, with each Settlement Item providing a detailed breakdown of the amount earned by the seller after applying the applicable commission and other financial adjustments.

# Purpose 

Associate individual Order Items with a Settlement.
Store the financial calculation for each settled Order Item.
Preserve the commission applicable to the Order Item.
Calculate the seller's net amount for each settled item.
Provide detailed settlement records for reconciliation and reporting.

# Attributes 

Attribute	Description
Settlement Item ID	Unique identifier for the settlement item
Settlement ID	Settlement associated with the item
Order Item ID	Order Item being settled
Seller ID	Seller receiving the settlement
Gross Amount	Gross amount generated by the Order Item
Commission Rate	Commission percentage applicable to the Order Item
Commission Amount	Marketplace commission deducted from the Order Item
Refund Amount	Refund amount deducted from the seller's settlement
Adjustment Amount	Other applicable financial adjustment
Net Amount	Final amount payable to the seller for the Order Item
Created At	Record creation timestamp
Updated At	Last modification timestamp 

# Validation Rules 

Every Settlement Item must belong to a valid Settlement.
Every Settlement Item must reference a valid Order Item.
Settlement Item Seller ID must match the Seller associated with the Settlement.
Settlement Item Seller ID must match the Seller associated with the Order Item.
Gross Amount cannot be negative.
Commission Rate must be between 0% and 100%.
Commission Amount cannot be negative.
Refund Amount cannot be negative.
Adjustment Amount must follow the configured adjustment rules.
Net Amount must be calculated correctly from the applicable financial values.
An Order Item must not be settled more than once for the same settlement period and settlement component.
Historical settlement calculations must not be recalculated using a newer commission configuration.

# Business Rules 

A Settlement Item represents one Order Item's contribution to a Settlement.
Only settlement-eligible Order Items can be included.
The applicable commission rate must come from the commission configuration applicable when the Order was created.
A newer commission rate must not change the commission of an existing Settlement Item.
Refunds related to the Order Item must be reflected in the applicable settlement calculation.
The seller's net amount must represent the amount payable after commission, refunds, and other valid adjustments.
A Settlement Item must remain traceable to its original Order Item.
An Order Item must not be settled multiple times for the same settlement period and financial component.
Sellers cannot modify Settlement Items.
The Super Admin can review Settlement Items according to administrative permissions.
Completed Settlement Items must not be modified in a way that changes historical financial records.
Settlement Item information must remain available for financial reconciliation and reporting.
Relationships

Belongs to one Settlement.
