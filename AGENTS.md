# Instructions for AI Agents

docs/SRS.md is the single source of truth. If any other file conflicts with it, the SRS wins. Do not read docs/archive/. Before implementing a feature, read its SRS section, the Entities docs and the API docs. Never mark a task done without a passing test.
Never fabricate quotes: when you cite a file, the quoted text must exist at that line. Verify with a search before you cite.
Do not edit prisma/schema.prisma, migrations, or src/ unless the task explicitly says so.
